# 射撃の敵候補索引

## 採用サイズ

80×80ワールド単位、既存タイルの2×2マス。2080×2080マップの水平空間を区切り、敵が存在する区画だけ持つ。80 / 120 / 160 / 240 / 320を比較し、分散時の改善と密集時の負荷の釣り合いから80を選んだ。大きい区画は分散時の所属更新が軽い一方、密集時に過剰な候補を拾う。

64体以下は射撃の全件確認を維持し、区画の保持・移動更新を省く。65体になった時だけ現在位置で索引を構築し、64体へ減ったら破棄する。射撃ごとの全敵へのラベル照合や、定期的な全敵の再分類はしない。

## 動作と互換性

- GameSessionの敵一覧自体が索引の所有者。追加・削除・一括死亡除去・初期化で登録を更新する。
- Enemy.moveToで座標と区画所属を同時に更新。通常移動・ノックバック・フック・Boss/Warden突進で共有する。登録後のx/y直接代入は禁止。
- 敵の大きさを含む水平矩形を関連区画へ登録。背負い袋は全方向を覆い、向きや袋の破壊による再登録を不要にする。従来の袋判定が射撃開始点の近くで保守的になるケースも維持する。
- 射線が通る行ごとに、弾幅を含む通過列の区画を参照する。斜め射線の大きな外接矩形全体は走査しない。
- 複数区画の同じ敵は問い合わせ番号で重複排除。候補一覧は射撃ごとのスナップショットで、ダメージ中の生成や移動によって反復対象が変わらない。
- 区画の所属削除は末尾要素との交換でO(1)。区画内で敵の並び順が変わっても、同距離の命中とビームの通知順は元の世界一覧順で解決する。
- 通常弾・散弾・跳弾・ビーム・ロケット直撃の候補だけに適用。正確な命中・遮蔽・HS・貫通・威力・射程・弾薬・報酬は既存のルールを使う。範囲攻撃、自動照準、味方、敵弾の検索は対象外。

## 計測

ShotGridBenchmarkは固定シードで32 / 128 / 512 / 2048体、分散配置と480×240の密集配置を用意する。分散配置は本番マップの解放済み床から選ぶ。各試行で240回の全敵移動更新と2880本の射線を処理する。射程は200〜2942、幅は2または20。ウォームアップ後7回の中央値を出す。

計測範囲は所属更新・候補検索・既存の簡易命中判定。壁・詳細3D判定・通信・描画を含まないため、ゲーム全体のFPS改善率を示すものではない。密集配置では改善が小さくなる。

2026-10-14、ローカルJava 23での一例。各時間は240回の更新全体の中央値（ms）。サイズ0は従来のArrayList全件確認。

| 区画サイズ | 2048体・分散 | 2048体・密集 |
| --- | ---: | ---: |
| 0（従来） | 127.55 | 121.45 |
| 80 | 45.84 | 113.02 |
| 120 | 39.43 | 130.40 |
| 160 | 37.44 | 142.06 |
| 240 | 39.72 | 152.39 |
| 320 | 39.62 | 171.74 |

80採用時、512体・分散では1射線の候補が平均15.0体（時間33.31→15.53ms）、密集では142.0体（30.29→27.21ms）。2048体では分散60.9体、密集562.8体。分散だけを最適化せず密集時の悪化を抑えるため80を選ぶ。

小集団では改善を保証しない。32体は全件確認へ戻すが、一覧管理の差は残り、分散例で1.81→3.55ms、密集例で1.76→2.12msだった（いずれも240回分）。128体・分散例も8.50→10.18ms、密集例7.44→7.32msと、配置・JIT・計測揺れの影響を受ける。64体以下の区画保持を省く判断と、全体FPSではない上記の計測範囲を区別する。

再計測はserverディレクトリで実行する。

```powershell
.\mvnw.cmd package -q
java -Xms256m -Xmx512m -cp 'target/test-classes;target/core-defense-server.jar' example.ShotGridBenchmark
```

## 検証

EnemySpatialIndexTestで5種類の区画サイズ・計1万本の射線を従来の全件判定と比較する。境界、太い弾、袋、逆方向、射程ゼロ、体内からの3D射線、移動、生成、削除、初期化、64/65体の切替も確認する。

CombatSpatialIndexTestは全武器×左右の手×2D/FPSについて、従来一覧と索引で命中イベント・HP・袋HP・座標・消費・報酬・クールタイムを比較する。追加生成やノックバック等の後に続けて撃った場合も比較する。既存サーバー全体のテストも実施する。
