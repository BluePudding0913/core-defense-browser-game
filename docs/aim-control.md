# 共通照準・呼吸円の仕様

## 対象と表示

対象はpistol、smg、rifle、revolver、lmg、shotgun、ricochet、freezeGun、sniperの9種類。
通常の銃は右クリック長押しで構える。構え中は通常レティクルに代わり、実際の散布角を示す呼吸円を表示する。腰撃ちにも同じ精度判定を適用するが、通常レティクルを表示する。デバッグ時は内部の散布円を青く表示する。
スナイパーは従来の右クリック短押しによる4×→8×→解除を維持し、立ち撃ちでスコープを使う場合も呼吸円を表示する。伏せ固定中は構えの有無にかかわらず円を表示する。倍率変更だけで内部精度は上がらない。
Attackerの右クリックは従来のサブ射撃を維持する。マウス中央で構え、スナイパーなら短押しで倍率を切り替える。他ジョブでも中央ボタンで構えられる。Tank・Scout・Spyの固有右クリック操作はAlt＋右クリックでも使用できる。

## 呼吸・移動・照準の安定

通常の呼吸は2.8秒周期で、基準の散布半径の65%〜135%を滑らかに往復する。周期はサーバーのプレイヤー時刻に従い、右クリック・持ち替え・射撃ではリセットしない。新しい試合では初期化する。

最終半径 = 呼吸による半径 × (1 + 1.25×移動成分 + 照準変更成分 + 空中なら0.8)

- 移動成分はサーバーが実際の移動距離から算出した速度÷通常歩行速度。上限1.8。通常歩行では半径2.25倍、通常ダッシュでは約3.05倍になる。壁に押し付けていて実際に動いていない場合は、入力だけで移動中と判定しない。
- 停止後は移動成分が指数的に回復する。時定数0.25秒、約0.75秒で残り約5%。急停止できても円が即座に最小になるわけではない。逆方向キーへの追加ボーナスは導入していない。
- 照準変更成分は上下を含む3Dの角速度から算出する。毎秒約20度までは滑らかな追従として追加ペナルティなし。それ以上は角速度に応じて増加し、最大1.5。回復の時定数0.22秒、約0.66秒で残り約5%。
- ジャンプ中は半径倍率に0.8を加える。接地判定を使用するため、バリケード上に着地しているだけでは空中扱いにしない。
- 移動と照準の安定度は持ち替えや右クリックでリセットしない。回復にはサーバーの時間経過が必要で、入力を大量送信しても早まらない。

スナイパーの伏せ固定は既存の特殊呼吸を維持する。各周期20%の特別な収縮、直前の最大拡大だけ6%増加、固定時間180秒までの最大65%縮小、発射後の一時的な拡大を残す。その半径に共通の移動・照準変更ペナルティを適用する。発射しても固定時間による縮小はリセットしない。既存の伏せ中の長射程・実際の高さによるヘッドショット判定も維持する。

## サーバー判定と通信

AimControlRulesが純粋な計算とプレイヤーごとの状態を持ち、GameSessionが更新・入力・実移動を連携する。CombatSystemは人間・CPU・Attackerのサブ射撃で共通の半径を使用する。通常弾は発射ごと、ショットガンは各ペレット、反射銃は反射前に一度、照準に垂直な円内を面積一様に抽選する。
LOOKは通常の操作中に最大20回/秒で方位と仰角を送る。角速度の分母はサーバー時刻で、クライアントから安定度や速度を申告しない。FIRE側でも照準変更を検証するため、LOOKを省略して急に別方向へ撃っても精度判定を通る。
表示した呼吸時刻を射撃時に送信し、サーバー時刻の過去200ms〜先行60msかつ単調増加の範囲だけ受け付ける。無効な射撃時刻は発射・弾薬消費の前に拒否する。伏せスナイパーは既存の呼吸時刻検証を使用する。連射中の古い時刻は範囲を外れたら現在のサーバー時刻へ切り替える。サーバーが円の大きさと命中・ダメージを決め、クライアントは配信状態から表示を補間する。
精度状態はバックアップに複製し、新規試合で初期化する。

## 今回の保留

ロケット、レールガン、レーザー砲、火炎放射器、毒ガス、リパルサー、フック、バット、プラズマブレード、ドローン搭載武器、設置タレットは今回の共通精度変更の対象外。既存の散布・範囲・固定照射などを維持する。

## 命中表示

自分の攻撃でサーバーがダメージを確定した敵だけ、全身を180ms赤く表示する。他プレイヤーの命中やダメージ0の通知は対象外。赤色が終わると通常色、または凍結など現在の状態色へ復帰する。既存の命中マーカーと赤いパーティクルも維持する。

## 共通の上方向の反動

対象9種類の銃は発射通知に合わせて実際の視線が上へずれる。銃のアニメーションが落ち着いても視線は自動で元へ戻らず、マウスで補正する。スナイパーの強い反動と僅かな左右のずれは維持する。散弾の各ペレット通知を重複した発射として数えない。
一発の上昇角はpistol約0.52度、smg約0.17度、rifle約0.86度、revolver約1.32度、lmg約0.23度、shotgun約1.03度、ricochet約0.69度、freezeGun約0.52度、sniper約2.58度。反動演出はクライアントで適用し、その後の照準変更はサーバーの共通精度判定へ反映する。レールガンの視線固定中は固定を優先する。
