# 不具合・改善の報告

現在は正式リリース前の開発版です。通常の不具合や改善案は、開発者と連絡を取っている窓口へ以下を添えて伝えてください。公開用の問い合わせ先はリリース前に確定します。

```text
概要：
発生日時：
バージョン／コミット（分かれば）：
端末・OS・ブラウザ：
デバッグモード：ON / OFF
人数・ジョブ・ラウンド：
再現手順：
期待した動作：
実際の動作：
再現頻度：毎回 / ときどき / 1回のみ
```

画像やエラーがあれば添えてください。URLのクエリ文字列、合言葉、アクセスキー、セッションID、個人情報は除いてください。ブラウザの保存データをそのまま貼り付ける必要はありません。

脆弱性など、他のプレイヤーに影響する問題は公開の不具合報告に載せず、[Security policy](../SECURITY.md)の非公開窓口を使ってください。
