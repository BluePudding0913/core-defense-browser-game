# CORE DEFENSE 詳細設計・実装計画

## 1. ゲームの目的

本作は、スマートフォンのブラウザから遊べる4人協力型2D防衛アクションゲームとする。

研究施設中央のCOREを、施設外周にある複数の扉・搬入口・換気口から侵入する敵から守る。プレイヤーは直接戦闘に加え、罠、タレット、バリケード、CORE強化へ共有クレジットを配分し、最終ラウンドの敵を全滅させることを目指す。

勝利条件は最終ラウンドの全敵撃破。敗北条件はCORE HPが0になる、または全プレイヤーが同時にダウンすること。

列車脱出、POWER、FUEL、SIGNAL、TRACKは通常ゲームから廃止する。

## 2. 1試合の進行

1試合は12ラウンドで構成する。

1. 準備時間
2. 武器・弾薬・回復の購入
3. 罠の設置・修理
4. 防衛エリア解放・CORE強化
5. ラウンド開始
6. 抽選された1～複数の侵入口から敵が順次出現
7. 敵を全滅させる
8. ラウンド報酬を獲得
9. 次の準備時間へ移行

準備時間は20秒。プレイヤーは準備完了操作で早送りできる。

## 3. ラウンド構成

- ラウンドが進むほど敵総数、HP、移動速度が増える
- 研究施設外周に扉、搬入口、換気口、廃棄トンネルなど8か所の出現候補を置く
- 出現地点はラウンド開始時に抽選し、準備時間中には予告しない
- ROUND 1～2は1か所中心。以降は1～5か所を変化させ、同じ構成の連続を避ける
- 戦闘開始後は使用中の侵入口だけを赤く強調し、敵の流れを見て即座に配置を変える攻略要素とする
- ROUND 3以降は高速型が出現する
- ROUND 5以降は大型型が出現する
- ROUND 12では通常敵、高速型、大型型に加えてボスが出現する
- 未出現数と生存数が両方0になった時点でラウンドクリア

最終ラウンド撃破時は「ALL HOSTILES ELIMINATED / CORE SECURED」と表示する。

## 4. CORE

初期値はHP 1000、シールド0、防御レベル0、自動修復レベル0。

共有クレジットで以下を強化できる。

- 最大HP：最大HPと現在HPを増加
- シールド：各ラウンド開始時に補充される追加耐久値
- 防御：COREが受けるダメージを軽減
- 自動修復：ラウンド中にCORE HPを徐々に回復

敵は基本的にCOREへ進行し、到達すると継続攻撃する。

## 5. マップ

COREを中心に、主廊下、分岐通路、研究室、保安区画、製造区画を持つ研究施設として構成する。

```text
 AIRLOCK   VENT ── 研究室群 ── REACTOR DUCT
    │       │          │            │
WEST ACCESS ──────── CORE ───── LOADING BAY
    │       │          │            │
 WASTE   TUNNEL ── 研究室群 ── SERVICE VENT
```

主廊下にはCORE寄りの初期罠スロットを配置する。BIO LAB、SECURITY LAB、FABRICATION LABは開始時に封鎖され、入口端末へ共有クレジットを支払うと解放される。

解放後は区画内へ実際に進入でき、各区画にある2個の専用防衛スロットを使用できる。早い段階で迎撃地点を増やせる一方、防衛範囲が広がりプレイヤーが分散する。

## 6. プレイヤー

- 1〜4人。空席はCPUが担当
- HP 100
- HP 0でダウンし、低速移動のみ可能
- 味方が4秒間操作するとHP 45で蘇生
- 全員同時ダウンで敗北
- CPUは担当レーンの防衛、敵への攻撃、味方蘇生を行う
- CPUは共有資金を自動使用しない

## 7. 操作

- 左側の空き部分を短く長押しして仮想スティックを表示
- PCではWASDまたは矢印キー
- 画面のDASHボタンまたはShiftキーを押しながら移動するとダッシュ
- ダッシュ中はスタミナを消費し、通常移動中または停止中に回復する
- スタミナを使い切った場合は一定量まで回復してから再使用できる
- 敵をタップして攻撃
- 罠スロット、ショップ、CORE、倒れた仲間をタップして操作
- 敵や操作対象のタップ判定を移動より優先
- ショップ、回復、建設、修理、CORE強化、区画解放は準備中と戦闘中の両方で操作可能
- 戦闘中に施設メニューを開いても敵とラウンド進行は停止しない

## 8. 武器

| 武器 | 入手 | 役割 |
|---|---:|---|
| ピストル | 初期 | 弾薬無限、短い射撃間隔の標準武器 |
| バット | 初期 | 短射程、大ノックバック |
| ショットガン | 購入 | 短中距離、範囲攻撃、有限弾薬 |
| ライフル | 購入 | 長射程、高威力、有限弾薬 |

攻撃成功時は射線、衝撃、ダメージ数値を全クライアントへ配信する。

## 9. クレジット

クレジットはチーム共有とする。

- 敵撃破報酬
- ラウンドクリア報酬

使用先は武器、弾薬、回復、罠、修理、エリア解放、CORE強化。個人火力とチーム防衛のどちらへ投資するかが中心的な判断になる。

## 10. 罠・防御設備

完全自由配置ではなく、レーン上の固定スロットへ設置する。

- AUTO TURRET：射程内の敵を継続攻撃
- BARBED WIRE：周囲の敵を減速
- MINE：接近した敵へ範囲ダメージを与えて消滅
- BARRICADE：敵を停止させ、破壊されるまで時間を稼ぐ

設備には耐久値があり、敵の通過・攻撃で損耗する。準備時間中・戦闘中ともクレジットで修理できる。

## 11. 敵

- GRUNT：標準型
- RUNNER：低HP、高速
- BRUTE：高HP、低速、高攻撃力
- BOSS：最終ラウンド限定

敵の最終目標はCORE。近距離にプレイヤーがいる場合はプレイヤーを攻撃し、バリケードが進路を塞ぐ場合はバリケードを優先して破壊する。

## 12. 画面表示

- 現在ラウンド / 最終ラウンド
- 準備または戦闘フェーズと残り時間
- 戦闘中に使用されている侵入口の発光表示
- CORE HP、シールド
- 未撃破敵数
- 共有クレジット
- チームHPは小型の横並び表示にまとめる
- 武器ボタン内に武器名・弾薬・クールタイム残り秒数を表示する
- 武器ボタン外周をクールタイム回復ゲージとして使用する
- ダッシュスタミナはDASHボタンと一体化し、独立した大型パネルを置かない
- タップ対象に応じた購入・建設メニュー

常時表示はCORE、ラウンド、クレジット、簡易チームHP、ダッシュ、武器に限定し、操作説明などの常設テキストは表示しない。

## 13. サーバー責務

位置、衝突、敵AI、スポーン、ダメージ、罠、購入、クレジット、ラウンド進行、CORE、勝敗はJavaサーバーを正とする。ブラウザは入力意図を送り、受信した状態を描画する。

自分のキャラクター移動はブラウザ側でも同じ速度・衝突・ダッシュ・スタミナ計算を即時実行する。サーバーの正式位置との差が小さい場合は段階的に補正し、大きくずれた場合やフェーズ変更時は正式位置へ戻す。他プレイヤーと敵は従来どおり受信状態を補間して描画する。

## 14. 初回再構築の完成条件

- 12ラウンドが準備と戦闘を交互に進行する
- ラウンドごとに選ばれた施設外周の侵入口から敵がCOREへ進軍する
- CORE破壊・全員ダウン・最終ラウンド全滅の勝敗が成立する
- 4武器、弾薬、購入が動作する
- 4種の罠、耐久、修理が動作する
- 3つの閉鎖エリアへの進入、専用スロット解放とCORE 4系統強化が動作する
- CPU補充、攻撃、レーン防衛、蘇生が動作する
- スマートフォンの直接タップ操作で一連のゲームループを完結できる
