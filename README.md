# CORE DEFENSE

スマートフォン・PCのブラウザで遊べる、4人協力型の2D防衛アクションゲームです。武器や防衛設備を整え、COREを50ラウンド守ります。空席はCPUが担当するため、1人でも遊べます。

現在はローカルでプレイを確認しながら開発中です。将来はインターネット上で公開し、離れたプレイヤー同士で遊べるようにする予定です。

ROUND 12から砲撃手（ARTILLERY）が出現します。通常の敵枠での出現率はROUND 25まで4%、ROUND 26以降は8%です。射程420以内の見通せるプレイヤー、設備、COREを狙い、4秒間隔で酸弾を発射します。通常・銅・銀タレットは標的にせず、酸弾のダメージも受けません。半径64の予告円が出てから1.5秒後に着弾するため、円の外へ移動すると回避できます。壁越しには攻撃せず、着弾時の範囲ダメージも壁に遮られます。近距離では移動・近接攻撃に戻り、CPUも着弾予告を見て回避します。

回復キットのキーは初期Hです。メインメニューの「設定」で回復キットの欄を選び、割り当てたいキーを押すとブラウザに保存されます。移動や所持品などで使用中のキーは割り当てできません。

ROUND 5～10は敵の数と出現ペースを抑え、ROUND 6は20体、ROUND 7は23体になります。盾持ちはROUND 7で4%、ROUND 8で7%、ROUND 9以降は10%の確率で出現します。

デバッグモード（URLに`?debug=1`を付けて開始）ではGoldと武器を所持して開始します。敵の出現は通常モードと同じです。

## ローカルで遊ぶ

JDK 17以上が必要です。Mavenの事前インストールは不要です。

1. `test-build-and-run.bat`を実行します。
2. <http://localhost:8080/client/> を開きます。
3. 「クイックマッチ」または「合言葉」で参加し、ゲスト全員の準備完了後にホストが開始します。1人ならすぐに開始できます。

ビルド済みなら`run-existing-jar.bat`で起動できます。終了時は、起動した2つのウィンドウを閉じてください。

スマートフォンでは同じWi-Fiに接続し、`http://PCのローカルIP:8080/client/`を開きます。PCのファイアウォールで8080・8887番ポートの許可が必要です。

## 基本操作

| 操作 | PC |
| --- | --- |
| 移動・ダッシュ | WASD／矢印キー・Shift |
| 射撃・連射 | 左クリック・長押し |
| 購入・クラフト・設置・設備操作 | R（長押しでCOREや設備を持ち上げ） |
| 所持品 | E |
| 武器・設置物の切り替え | マウスホイール・数字キー1〜9 |
| 回復キット使用 | H |

スマートフォンでは仮想スティックと画面上のボタンを使います。詳しいルールはゲーム内の「遊び方」を参照してください。

外エリア左のRECOVERY ROOMは4マス幅の通路でつながっています。解放後、MED BAYの近くにいると無料で回復します。準備中は毎秒100HP回復し、被弾後の待ち時間もありません。戦闘中は毎秒4HP回復し、被弾すると5秒間停止します（追加の被弾で待ち時間がリセット）。回復キットは奥側のINFIRMARY（医務室）のMEDKITショップで120Gで購入できます（HP +60、最大5個）。

エリア解放は端末ごとの固定価格です。解放数による値上がりはありません。価格はサーバーの`GameConfig.AREA_UNLOCK_COSTS`で個別に設定します。

| エリア | 解放費用 |
| --- | --- |
| ENTRY ROOM | 150G |
| TRANSIT HALL / INFIRMARY | 各350G |
| FOREST LAB / RELAY GALLERY / MINE LAB | 各1,000G |
| SECURITY HALL / COMMAND ROOM | 各5,000G |
| WOOD ROOM / ORE ROOM / RECOVERY ROOM | 200G / 300G / 250G |
| TIME CONTROL | 500G |
| SHOTGUN ROOM / RICOCHET ROOM | 各300G |
| SMG ROOM / LMG ROOM | 500G / 3,000G |
| RIFLE ROOM / REVOLVER ROOM | 各5,000G |
| SNIPER ROOM | 7,500G |
| HEAVY ARMS | 30,000G |

RECOVERY ROOMは外エリアと同程度の広さで、壁に凹凸のある自然な輪郭になっています。敵の湧き口は外エリアと同じ7か所です。解放済みならROUND 8から湧き口が選択候補に入り、ROUND 12以降は全7か所が有効になります。回復中は淡い緑の粒子がプレイヤーの体に集まります。

CPUは準備中にHP85未満、戦闘中にHP55未満で安全なMED BAYへ向かいます。準備中は全回復、戦闘中はHP90まで回復して復帰します。敵や砲撃がいる医療施設は避け、緊急時は携帯キットを使用します。キットは準備中に独立ショップで1個補充します。

## 開発

効果音は`client/sound.js`でWeb Audio APIを使って合成します。MP3ファイルによる再生は使用しません。音声合成は`node client/tests/sound.cjs`、ゲームイベントからの呼び出しは`node client/tests/gameplay-ui.cjs`で確認します。

- `client/`：ブラウザ画面・入力・描画
- `server/`：Java製WebSocketサーバー・ゲームルール
- `shared/map.json`：マップ・施設配置・販売価格（変更後はサーバーを再ビルド）
- `server/src/main/java/example/WeaponCatalog.java`：武器性能・弾薬容量・攻撃方式（ブラウザにも配信）
- `server/src/main/java/example/GameConfig.java`：ラウンド・建築・回復などの設定

責務分離の現状と、機能変更時の分割手順は[開発構成](docs/architecture.md)を参照してください。

サーバーのテストは`server/`で`.\mvnw.cmd test`、ビルドは`.\mvnw.cmd package`を実行します。ビルド時にもテストが実行されます。
クライアントのテストはプロジェクト直下で`node client/tests/menu-ui.cjs`などを実行します。`rooms-server.cjs`にはビルド済みサーバーとNode.js 22以上が必要です。

HEAVY ARMSのRAILGUNは20,000G、最大8発。攻撃を長押しすると1.2秒チャージし、幅1マス・射程2,400の青白いビームを3秒間照射します。0.1秒ごとに300ダメージ（最大9,000）を与え、敵と盾を貫通し、壁で止まります。方向は発射時に固定され、照射中は通常の30%の速度で移動できます。弾は照射開始時に1発消費し、攻撃を離すと中断、照射終了後は2秒冷却します。チャージ中の移動速度は60%で、途中キャンセルは弾を消費しません。

## インターネット公開に向けて

ブラウザ画面とJavaゲームサーバーを公開環境に配置し、HTTPS／WSSで接続できるようにする予定です。サーバーにはTLS・接続元制限・アクセストークンの設定があり、公開前に利用者認証・接続数制限・監視などを整えます。設定と現在の制約は[SECURITY.md](SECURITY.md)を参照してください。

### BOMBER

ROUND 6から自爆虫が10%の確率で出現します。生存中は通常の敵と同様に移動・攻撃し、倒された時だけ半径4マスの爆発でプレイヤー・防衛設備・COREにダメージを与えます。接近による自爆やカウントダウンはありません。壁越しには当たりません。他の敵にはダメージを与えず、自爆虫同士も連鎖しません。

### EXPLOSION BOSS

ROUND 25・35・45で爆発ボスが1体出現します。4ラウンド周期の他のボスとは同じラウンドに出現しません。黒い六角形に赤い目を持ち、HPは10億、被ダメージは0.1％、移動速度は基本12です。近接攻撃はせず、ヘッドショット倍率・報酬もありません。胴体・頭のどちらにも同じ減衰後ダメージが入ります。

爆発ボスを除く生存敵と未出現敵の合計がラウンド開始時の総敵数の5％未満になると、30秒のカウントが始まります。カウント中は徐々に速く点滅し、最後に半径12マス以内のプレイヤーへ標準体力の110％（110）のダメージを与えて消滅します。距離による減衰や壁による遮断はなく、タレットを含む設備にはダメージを与えません。

爆発後はその場にランナー5体が出現し、全て倒すまでラウンドは続きます。

出現場所は解放済みの戦闘エリアのうち、初期CORE位置から通路に沿った距離が最も長い奥の入口を優先します。到達可能な候補がない場合は通常のラウンド入口から出現します。資源用の小部屋やTIME CONTROLは対象外です。

デバッグモード（`?debug=1`）ではROUND 1の砲撃手に続いて1体出現します。通常敵の出現枠を使うため、初期の総敵数は変わりません。自爆虫のデバッグ用出現・早期解禁はありません。

Drone Operator: 所持品でDRONEを選んでRを押し、出撃前の選択画面で所持武器1つ、またはUNARMEDを選ぶと出撃します。搭載武器は出撃中に本人が使えなくなり、回収すると戻ります。弾薬は本人の所持弾から消費します。攻撃で得るゴールドは通常の半分です。壊れたDRONEを選択中でも、施設の近くではRで施設を利用できます。ロケット・レールガン・LMG・バットは搭載できません。WASD／移動パッドと通常の射撃操作で偵察・攻撃し、R短押しで操作先を切り替えます。本人視点ではドローンはその場に留まり、命中した敵からの敵対が続きます。本人の近くへ戻り、壁越しでない位置でRを長押しすると回収できます。操作中は本人がその場に残って被弾します。ドローンは壁と未解放区画を通れませんが、防衛設備の上を飛べます。ドローンの体力は45です。ドローン視点は停電の視界制限を受けず、薄い緑の暗視表示になり、本人の視点に戻ると通常の制限に戻ります。破壊時は搭載武器とその残弾も失います。再出撃時に鉱石5・銅2を消費して機体を修復し、必要なら別の所持武器を搭載します。回収だけではHPは回復しません。
