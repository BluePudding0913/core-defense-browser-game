# CORE DEFENSE プロトタイプ

スマートフォンのブラウザから遊べる、4人協力型2D防衛アクションゲームです。
参加者が4人未満の場合はCPUが空席を担当します。

旧仕様の列車脱出ゲームから全面的に再構築し、現在は防衛拠点内のCOREを複数ラウンド守るゲームになっています。詳細設計は[plan.txt](plan.txt)を参照してください。

## 現在遊べる内容

- 準備と戦闘を繰り返す全12ラウンド
- 作成者名付きのルーム一覧、ルーム作成・参加、全参加者のOK確認と作成者だけが押せるSTART
- 約8×12タイルの不整形な屋外から、主導線1本に部屋と中継防衛区画を並べ、素材・時間制御の小部屋だけを脇道に置いた52×52タイルのマップ
- 順番に解放する入口区画、TRANSIT、武器庫、森林、RELAY、鉱山、SECURITY、最奥の指令室と、WOOD・ORE・TIME CONTROLの有料脇道区画
- ラウンド進行に応じて候補が増える、屋外7か所の敵出現地点
- GRUNT、RUNNER、BRUTE、複数同時に現れることがあるBOSS
- 停電、扉故障、ボス襲撃などのラウンドイベント
- BOSSがCORE周辺へ放つパルス攻撃
- 解放済みの好きな床へ移設できるCOREと、HP、シールド、防御、自動修復アップグレード。運搬中は低速になり、運搬者の被ダメージがCOREにも伝わる
- 与えたダメージに応じて本人が獲得する個人ゴールド、敵付近のライトブルー獲得表示、全員が受け取るラウンドクリア報酬
- ピストル、バット、ショットガン、SMG、ライフル、スナイパーライフル
- 壁で止まり、壁越しの敵には命中しない射撃
- 基本射撃では敵を押し戻さず、バットとショットガンだけが持つノックバック
- 一本道上の別々のエリアに分散した1タイル・1商品のショップで、ショットガン、SMG、ライフル、スナイパーライフル、弾薬を購入
- 有料のWOOD・ORE区画や奥の森林・鉱山で素材へ近づいて自動回収し、複数の作業台でBLOCK、AUTO TURRET、BARBED WIRE、MINE、BARRICADEをクラフト
- TIME CONTROL区画の装置で、準備中は現在の休憩、戦闘中は次の休憩を10Gにつき1分延長
- クラフト品を選択すると正面1タイルを色付き表示し、Rで自由建築。設備の修理と回収にも対応
- ダウン、4秒蘇生、全員ダウンによる敗北
- 不足人数を補うCPUの脅威評価、射線・射程に応じた武器選択、分散防衛、安全確認付き蘇生
- スマートフォン用仮想スティック、照準方向への射撃、PCのRキーによる統一インタラクション
- スタミナを消費するダッシュ（PCのShiftキー）
- 攻撃、爆発、CORE被弾、蘇生、全画面ラウンド開始のエフェクト
- サーバー側での位置、敵AI、購入、罠、CORE、ラウンド、勝敗管理
- 自分の移動を入力直後に表示し、サーバー位置へ滑らかに補正するクライアント予測

## 起動方法

必要なものはJDK 17以上です。Mavenの事前インストールは不要です。

### もっとも簡単なテスト起動

プロジェクト直下の`test-build-and-run.bat`をダブルクリックしてください。サーバーをビルドしたあと、ゲームサーバーとブラウザ用サーバーを起動します。ブラウザは自動では開かないため、遊ぶときだけ <http://localhost:8080/client/> を開いてください。

すでに`server\target\core-defense-server.jar`がある場合は、`run-existing-jar.bat`をダブルクリックするとビルドを省略して、そのJARとブラウザ用サーバーだけを起動できます。JARがない場合は何もビルドせず、案内を表示して終了します。

終了するときは、同時に開いた2つの黒いウィンドウを閉じてください。

### 1. ゲームサーバー

PowerShellを開き、次を実行します。

```powershell
cd server
.\mvnw.cmd package
java -jar target\core-defense-server.jar
```

### 2. ブラウザ画面

別のPowerShellを開き、プロジェクトのルートで次を実行します。

```powershell
jwebserver -p 8080
```

ブラウザで <http://localhost:8080/client/> を開きます。名前を入力してルームを作成するか、作成者名が表示された既存ルームを選びます。参加者全員が`OK`を選ぶと、作成者が`START`を押せます。複数タブを開けば複数人接続を確認できます。

スマートフォンから試す場合はPCと同じWi-Fiに接続し、`http://PCのローカルIP:8080/client/`を開きます。PCのファイアウォールでポート8080と8887の許可が必要です。

### Cloudflare Dropへ画面をアップロードする場合

`client`フォルダをアップロードすると、開始画面などの静的ファイルを公開できます。マップはクライアントへ同梱せず、接続時にゲームサーバーから受信します。Cloudflare Dropは静的ファイルだけを公開するため、実際に遊ぶにはJavaゲームサーバーを別途起動し、HTTPSページから接続できるWSSとして公開する必要があります。

## 公開・運用上の注意

このリポジトリは開発中のプロトタイプです。ソースコードをGitHubで公開することはできますが、現在のゲームサーバーはローカル環境または信頼できる家庭内LANでのテストを想定しています。

認証、暗号化されたWebSocket接続、接続元制限、本番向けのアクセス制限はまだありません。ポート8887をインターネットへ直接公開しないでください。一般公開サーバーとして運用する場合は、TLS対応のリバースプロキシ、認証、接続元検証、アクセス頻度制限、監視を追加する必要があります。詳細は[SECURITY.md](SECURITY.md)を参照してください。

GitHub PagesだけではJava製ゲームサーバーは起動しません。ブラウザ部分とは別に、ゲームサーバーを実行できる環境が必要です。

## サーバーコードの構成

- `WasdServer.java`：WebSocket接続、切断、入力受信、定期更新
- `GameSession.java`：ラウンド進行、戦闘、購入、CPUなどのゲームルール
- `GameMap.java`：タイル、追加の脇道区画、侵入口、資源／クラフト施設、自由建築可否、衝突判定
- `shared/map.json`：サーバーとブラウザが共通利用するマップ定義
- `GameEntities.java`：プレイヤー、敵、防衛設備の状態
- `SnapshotBuilder.java`：ブラウザへ送る状態データの生成
- `GameConfig.java` / `GameSupport.java`：共通設定値と小さな共通処理

基本マップは`shared/map.json`、追加の脇道区画と複数作業台は`GameMap.java`で管理します。Javaサーバーが両者を統合し、接続したブラウザへ送信します。クライアント側にはマップ定義を保持しません。変更後はサーバーを再ビルドしてください。

## サーバーの自動テスト

サーバーのルール変更後は、次のコマンドで自動テストを実行できます。

```powershell
cd server
.\mvnw.cmd test
```

共通マップ、経路と衝突判定に加え、ラウンド進行、購入、方向射撃と連射、素材採取、クラフト、設置、蘇生、再接続、敵の優先行動、ラウンドイベントを検証します。通常の`package`実行時にも同じテストが実行され、失敗した場合はJARを作成しません。

クライアントからの操作には連番を付け、サーバーの状態通知には処理済み番号を含めています。位置予測は未確認の移動入力を考慮して補正します。通信が切れた場合は30秒間プレイヤー枠を保持し、同じタブからの再接続時に名前、位置、武器などの状態を引き継ぎます。

## 操作

- スマートフォン：画面左側の空き部分を短く長押ししてからドラッグ
- PC：WASDまたは矢印キー
- ダッシュ：PCで移動しながらShiftキーを長押し
- 左クリック／画面右側タッチ：その方向へ射撃（敵を正確にクリックする必要なし）
- 左クリック／タッチ長押し：現在武器の最短射撃間隔で連射
- R（タッチ端末では表示されるRボタン）：近くの仲間、設備、ショップ、解放端末、作業台、COREを操作。ショップでは、その1ユニットが扱う1商品の購入確認を即座に表示
- E：所有武器、弾薬、素材、クラフト済み設置物の一覧を開閉。素材は1個または全量を地面へドロップ可能
- 開始画面またはEメニューの「遊び方」：目的、操作、防衛の広げ方、画面表示を確認
- マウスホイール：武器と所持している設置物を前後に切り替え
- 数字キー1〜9：一覧の番号に対応する武器・設置物へ直接切り替え
- 右下の武器表示をクリック：武器と設置物を順番に切り替え
- 武器表示下端の細い線：次に攻撃できるまでの回復ゲージ
- 森林／鉱山の素材：近づくだけで自動回収
- WORKBENCHでR：素材から防衛設備をクラフト（完成品は自動選択）
- Eで開く所持品画面：使用する武器や設置するクラフト品を選択
- クラフト品を選択中にR：最後に進んだ方向の正面1タイルへ設置
- COREでR：現在HPを確認。MOVE CORE選択後は、正面の解放済みタイルへRで設置
- 設置済み設備の近くでR：素材で修理、または所持品へ回収

敵はラウンド1から複数地点を使用し、そのラウンド中は同じ出現地点に固定されます。ラウンドが進むほど同時使用地点が増えます。出現地点は通常画面ではマップ上に表示されません。敵は小さな屋外から、解放した部屋をつなぐ一本の導線へ侵入します。COREを奥へ移すほど防衛線も段階的に移動します。敵ごとに進行方向を少しずらし、完全な一列には並ばないようにしています。

マップ調整時はURLへ`?debug=1`を付けると、全出現地点、進軍経路、現在使用中の地点をマップ上で確認できます。

侵入口ごとにRUNNERが多い、BRUTEが多い、プレイヤーを追いやすい、防衛設備を壊しやすいといった違いがあります。停電時は自分の周囲だけが見え、扉故障時は橙色の故障入口から敵が集中し、BOSSはCORE付近で範囲パルスを使用します。

購入、回復、採取、クラフト、建設、修理、CORE強化は準備時間中と戦闘中の両方で行えます。戦闘中も敵の攻撃は止まらないため、周囲の安全を確認して利用してください。

ゲーム中のUIは白・黒・灰色を基本に、状態を伝えるライトブルーとレッドだけをアクセントにしています。上部中央に`ROUND 3`形式のラウンドと敵数／次ラウンド時刻、左下に自分の体力を示す1個のハートと`700G`形式のゴールド、右上に色付きの仲間HPバーとゴールド、右下に武器と攻撃クールダウンを表示します。プレイヤーのダウンは赤いログ、攻撃で得たゴールドは敵付近のライトブルー表示で確認できます。敵のHPバーは表示せず、命中時だけ敵が赤く光ります。COREはタイル内のライトブルーの割合、仲間は右上のバーで残りHPを確認できます。
