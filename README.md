# CORE DEFENSE

スマートフォン・PCのブラウザで遊べる、4人協力型の2D防衛アクションゲームです。武器や防衛設備を整え、COREを50ラウンド守ります。空席はCPUが担当するため、1人でも遊べます。

現在はローカルでプレイを確認しながら開発中です。将来はインターネット上で公開し、離れたプレイヤー同士で遊べるようにする予定です。

ROUND 12から砲撃手（ARTILLERY）が通常の敵枠の8%で出現します。射程420以内の見通せるプレイヤー、設備、COREを狙い、4秒間隔で酸弾を発射します。半径64の予告円が出てから1.5秒後に着弾するため、円の外へ移動すると回避できます。壁越しには攻撃せず、着弾時の範囲ダメージも壁に遮られます。近距離では移動・近接攻撃に戻り、CPUも着弾予告を見て回避します。

デバッグモード（URLに`?debug=1`を付けて開始）ではROUND 1の自爆虫3体に続いて砲撃手が出現し、その後も最初から出現候補に入ります。

## ローカルで遊ぶ

JDK 17以上が必要です。Mavenの事前インストールは不要です。

1. `test-build-and-run.bat`を実行します。
2. <http://localhost:8080/client/> を開きます。
3. 「クイックマッチ」または「合言葉」で参加し、ゲスト全員の準備完了後にホストが開始します。1人ならすぐに開始できます。

ビルド済みなら`run-existing-jar.bat`で起動できます。終了時は、起動した2つのウィンドウを閉じてください。

スマートフォンでは同じWi-Fiに接続し、`http://PCのローカルIP:8080/client/`を開きます。PCのファイアウォールで8080・8887番ポートの許可が必要です。

## 開発

- `client/`：ブラウザ画面・入力・描画
- `server/`：Java製WebSocketサーバー・ゲームルール
- `shared/map.json`：マップ・施設配置・販売価格（変更後はサーバーを再ビルド）
- `server/src/main/java/example/GameConfig.java`：武器性能などの設定

サーバーのテストは`server/`で`.\mvnw.cmd test`、ビルドは`.\mvnw.cmd package`を実行します。ビルド時にもテストが実行されます。
クライアントのテストはプロジェクト直下で`node client/tests/menu-ui.cjs`などを実行します。`rooms-server.cjs`にはビルド済みサーバーとNode.js 22以上が必要です。

## インターネット公開に向けて

ブラウザ画面とJavaゲームサーバーを公開環境に配置し、HTTPS／WSSで接続できるようにする予定です。サーバーにはTLS・接続元制限・アクセストークンの設定があり、公開前に利用者認証・接続数制限・監視などを整えます。設定と現在の制約は[SECURITY.md](SECURITY.md)、負荷検証は[測定結果](docs/room-performance-results.md)を参照してください。

### BOMBER

ROUND 6から自爆虫が10%の確率で出現します。生存中は通常の敵と同様に移動・攻撃し、倒された時だけ半径4マスの爆発でプレイヤー・防衛設備・COREにダメージを与えます。接近による自爆やカウントダウンはありません。壁越しには当たりません。他の敵にはダメージを与えず、自爆虫同士も連鎖しません。

### EXPLOSION BOSS

12ラウンドごとにボス枠の1体が爆発ボスになります。黒い六角形に赤い目を持ち、HPは10億、被ダメージは0.1％、移動速度は基本12です。近接攻撃はしません。

爆発ボスを除く生存敵と未出現敵の合計がラウンド開始時の総敵数の5％未満になると、60秒のカウントが始まります。カウント中は徐々に速く点滅し、最後に半径12マス以内のプレイヤーへ標準体力の110％（110）のダメージを与えて消滅します。距離による減衰や壁による遮断はなく、タレットを含む設備にはダメージを与えません。

デバッグモード（`?debug=1`）ではROUND 1の自爆虫・砲撃手に続いて1体出現します。通常敵の出現枠を使うため、総敵数は変わりません。
