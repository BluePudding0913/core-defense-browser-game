# CORE DEFENSE プロトタイプ

スマートフォンのブラウザから遊べる、4人協力型2D防衛アクションゲームです。
参加者が4人未満の場合はCPUが空席を担当します。

旧仕様の列車脱出ゲームから全面的に再構築し、現在はマップ中央のCOREを複数ラウンド守るゲームになっています。詳細設計は[plan.txt](plan.txt)を参照してください。

## 現在遊べる内容

- 準備と戦闘を繰り返す全12ラウンド
- 研究施設を模した部屋・主廊下・分岐通路
- 外周扉、搬入口、換気口など8か所からラウンドごとに変化する敵の出現地点
- GRUNT、RUNNER、BRUTE、最終ラウンドのBOSS
- COREのHP、シールド、防御、自動修復アップグレード
- 敵撃破とラウンドクリアで獲得するチーム共有クレジット
- ピストル、バット、ショットガン、ライフル
- ショットガンとライフルの弾薬購入
- AUTO TURRET、BARBED WIRE、MINE、BARRICADE
- 固定スロットへの建設、設備耐久値、修理
- BIO LAB、SECURITY LAB、FABRICATION LABの3つの探索エリア
- 各エリアを解放すると中へ進入でき、専用の防衛スロットを利用可能
- ダウン、4秒蘇生、全員ダウンによる敗北
- 不足人数を補うCPUのレーン防衛、攻撃、蘇生
- スマートフォン用仮想スティックと対象直接タップ
- スタミナを消費するダッシュ（画面ボタン／Shiftキー）
- 攻撃、爆発、CORE被弾、蘇生のエフェクト
- サーバー側での位置、敵AI、購入、罠、CORE、ラウンド、勝敗管理
- 自分の移動を入力直後に表示し、サーバー位置へ滑らかに補正するクライアント予測

## 起動方法

必要なものはJDK 17以上です。Mavenの事前インストールは不要です。

### もっとも簡単なテスト起動

プロジェクト直下の`test-build-and-run.bat`をダブルクリックしてください。サーバーをビルドしたあと、ゲームサーバーとブラウザ用サーバーを起動して、ゲーム画面を自動的に開きます。

終了するときは、同時に開いた2つの黒いウィンドウを閉じてください。

### 1. ゲームサーバー

PowerShellを開き、次を実行します。

```powershell
cd server
.\mvnw.cmd package
java -jar target\core-defense-server.jar
```

### 2. ブラウザ画面

別のPowerShellを開き、プロジェクトのルートで次を実行します。

```powershell
jwebserver -d client -p 8080
```

ブラウザで <http://localhost:8080> を開きます。複数タブを開けば複数人接続を確認できます。

スマートフォンから試す場合はPCと同じWi-Fiに接続し、`http://PCのローカルIP:8080`を開きます。PCのファイアウォールでポート8080と8887の許可が必要です。

## 公開・運用上の注意

このリポジトリは開発中のプロトタイプです。ソースコードをGitHubで公開することはできますが、現在のゲームサーバーはローカル環境または信頼できる家庭内LANでのテストを想定しています。

認証、暗号化されたWebSocket接続、接続元制限、本番向けのアクセス制限はまだありません。ポート8887をインターネットへ直接公開しないでください。一般公開サーバーとして運用する場合は、TLS対応のリバースプロキシ、認証、接続元検証、アクセス頻度制限、監視を追加する必要があります。詳細は[SECURITY.md](SECURITY.md)を参照してください。

GitHub PagesだけではJava製ゲームサーバーは起動しません。ブラウザ部分とは別に、ゲームサーバーを実行できる環境が必要です。

## サーバーコードの構成

- `WasdServer.java`：WebSocket接続、切断、入力受信、定期更新
- `GameSession.java`：ラウンド進行、戦闘、購入、CPUなどのゲームルール
- `GameMap.java`：壁、侵入口、解放エリア、防衛スロット、衝突判定
- `GameEntities.java`：プレイヤー、敵、防衛設備の状態
- `SnapshotBuilder.java`：ブラウザへ送る状態データの生成
- `GameConfig.java` / `GameSupport.java`：共通設定値と小さな共通処理

## 操作

- スマートフォン：画面左側の空き部分を短く長押ししてからドラッグ
- PC：WASDまたは矢印キー
- ダッシュ：移動しながら画面のDASHボタンを長押し、PCではShiftキーを長押し
- 敵をタップ：現在武器で攻撃
- 武器ボタン：所有武器を順番に切り替え
- 武器ボタン外周：次に攻撃できるまでの回復ゲージ。中央下に残り秒数を表示
- ダウンした仲間を長押し：蘇生
- 罠スロットをタップ：建設または修理
- ARMORYをタップ：武器と弾薬を購入
- MED BAYをタップ：HP回復
- COREをタップ：CORE強化
- 各閉鎖エリア入口のUNLOCK端末をタップ：対応エリアを解放
- 「準備完了」：残り準備時間を省略

敵の出現地点はラウンド開始時に決まり、事前には表示されません。戦闘開始後に赤く点滅する侵入口と敵の流れを確認し、その場で守る場所を判断してください。序盤は1か所中心、中盤以降は複数の扉や換気口から同時に侵入します。

購入、回復、建設、修理、エリア解放、CORE強化は準備時間中と戦闘中の両方で行えます。戦闘中も敵の攻撃は止まらないため、周囲の安全を確認して利用してください。

ゲーム中のUIは戦場を隠さないよう、上部にCORE・ラウンド・クレジットと小型のチームHP、右下にダッシュと武器だけを常時表示します。
