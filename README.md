# CORE DEFENSE プロトタイプ

スマートフォンのブラウザから遊べる、4人協力型2D防衛アクションゲームです。
参加者が4人未満の場合はCPUが空席を担当します。

防衛拠点内のCOREを50ラウンド守ります。ルームを作成すれば1人でもCPUと協力して遊べます。

## 現在遊べる内容

- 準備と戦闘を繰り返す全50ラウンド。ROUND1の表示から敵出現まで8秒の猶予、ラウンド間の準備は30秒
- 作成者名付きのルーム一覧、ルーム作成・参加、参加者の準備完了と作成者だけが押せる開始ボタン。作成者は準備操作不要で最初から青枠表示
- 約8×12タイルの不整形な屋外から、主導線1本に部屋と中継防衛区画を並べ、素材・時間制御の小部屋だけを脇道に置いた52×52タイルのマップ
- 順番に解放する入口区画、TRANSIT、武器庫、森林、RELAY、鉱山、SECURITY、最奥の指令室と、WOOD・ORE・TIME CONTROLの有料脇道区画
- 屋外7か所から離れた入口を選んで敵が出現。室内出現はROUND 8から入口区画、10からTRANSIT、以降2ラウンドごとに奥の区画へ段階解禁（解放済みのみ）。室内入口は13まで最大1か所、14以降最大2か所。TIME CONTROL・WOOD・OREの小部屋は出現元にせず、戦闘中の解放は次ラウンドから判定
- 通常敵・大型・ボスの速度は従来の50%、体力は200%。RUNNERは通常敵の約2.4倍の速度。通常枠の出現数は各ラウンド25%削減（初回9体）。1体あたりとラウンドクリアのゴールド報酬は維持
- GRUNT、RUNNER、BRUTE、複数同時に現れることがあるBOSS
- 停電、扉故障、ボス襲撃などのラウンドイベント
- BOSSがCORE周辺へ放つパルス攻撃
- 解放済みの好きな床へ移設できるCOREと、HP、シールド、防御、自動修復アップグレード。運搬中は低速になり、運搬者の被ダメージがCOREにも伝わる
- 与えたダメージに応じて本人が獲得する個人ゴールド、敵付近のライトブルー獲得表示、全員が受け取るラウンドクリア報酬
- ピストル、二連ピストル、バット、ショットガン、SMG、ライフル、スナイパーライフル、REVOLVER、LMG、ロケラン
- REVOLVERは威力180・射程500・発射間隔0.5秒・30発、購入1200G。二連ピストルは2発同時射撃で合計72ダメージ・射程340・発射間隔0.30秒・240発（120射）・購入400G
- ショットガンは照準方向へ4本の散弾を発射。各弾は直線で最初の敵に命中し、敵への自動補正はありません
- スナイパーとREVOLVERは射線上の複数敵を貫通します（壁は貫通しません）。REVOLVERは射程360、威力320、発射間隔1.6秒の短射程・高威力武器です
- ヘッドショットは通常の2倍ダメージと命中ごとに追加3G（通常のダメージ報酬に加算）
- 壁で止まり、壁越しの敵には命中しない射撃
- 基本射撃では敵を押し戻さず、バットとショットガンだけが持つノックバック
- メインルート脇の専用エリアを解放して武器を購入。SHOTGUN・二連ピストルはENTRY ROOM脇、SMGはARMORY WING脇、LMGはFOREST LAB脇、RIFLEはMINE LAB脇、REVOLVERは最奥手前のSECURITY HALL脇、SNIPERはCOMMAND ROOM脇に配置。AMMOはFOREST LAB内
- 有料のWOOD・ORE区画や奥の森林・鉱山で木材・鉄鉱石・銅・銀へ近づいて自動回収し、作業台で防壁、通常・銅・銀タレット、有刺鉄線、地雷、バリケードをクラフト
- MED BAYで回復キットを120Gで購入（最大5個）。Hキーまたは所持品から使用するとHPを60回復し、満タン時には消費しない
- TIME CONTROL区画の装置で、準備中は現在の休憩、戦闘中は次の休憩を10Gにつき1分延長
- クラフト品を選択すると正面1タイルを色付き表示し、Rで自由建築。設備の修理と回収にも対応
- ダウン、近くに4秒いるだけの自動蘇生（射撃・移動中も継続）、全員ダウンによる敗北
- 不足人数を補うCPUの脅威評価、武器選択、分散防衛と蘇生支援。施設へ移動して補給・回復し、停電復旧、採取、クラフト、設置・修理・回収、素材共有、エリア解放、CORE運搬・強化、必要時の準備延長を判断
- スマートフォン用仮想スティック、照準方向への射撃、PCのRキーによる統一インタラクション
- スタミナを消費するダッシュ（PCのShiftキー）
- 攻撃、爆発、CORE被弾、蘇生、全画面ラウンド開始のエフェクト
- サーバー側での位置、敵AI、購入、罠、CORE、ラウンド、勝敗管理
- 自分の移動を入力直後に表示し、サーバー位置へ滑らかに補正するクライアント予測

## 起動方法

### メニューとルーム参加

通常の `client/` がゲームサーバーへ接続するメニューです。初回はゲスト名を入力し、次回から保存済みの名前でメニューを表示します。

- 最初に「クイックマッチ」または「合言葉」を選択します。
- 「合言葉」から「ルーム作成」または「ルーム検索」へ進みます。作成には1〜32文字の合言葉が必須です。同じ合言葉は同時に複数の部屋で使用できません。相手も同じゲームサーバーに接続し、同じ合言葉で検索してください。前後の空白は無視します。
- 合言葉ルームはクイックマッチや公開ルーム一覧に表示されません。
- クイックマッチは空いている公開ルームへ参加し、部屋がなければ新しいルームのホストになります。
- 空席はCPUが自動で担当し、常に4人でプレイします。ゲスト全員が準備完了になるとホストが開始できます。1人の場合はすぐに開始できます。
- ホストが切断すると、接続中の参加者へホスト権限を引き継ぎます。

マップは実装済みのCORE DEFENSEのみです。以前のサンプルステージ1〜3とサンプル合言葉 `CORE` は廃止しました。

旧メニューは `?legacy=1` で利用できます。メニューの回帰確認は `node client/tests/menu-ui.cjs`、サーバーをビルドした後の複数接続テストは `node client/tests/rooms-server.cjs` で実行できます。

メインメニューの「設定」からポインターの色と大きさ（直径4〜32px）を変更できます。プレビューとゲーム画面に即時反映され、同じブラウザーで次回も使用できます。初期値は青（`#0078ff`）、6pxです。保存が許可されていない場合は、そのページを開いている間だけ反映されます。設定の回帰確認は `node client/tests/pointer-settings.cjs` で実行できます。

必要なものはJDK 17以上です。Mavenの事前インストールは不要です。

### もっとも簡単なテスト起動

プロジェクト直下の`test-build-and-run.bat`をダブルクリックしてください。サーバーをビルドしたあと、ゲームサーバーとブラウザ用サーバーを起動します。ブラウザは自動では開かないため、遊ぶときは <http://localhost:8080/client/> を開いてください。

すでに`server\target\core-defense-server.jar`がある場合は、`run-existing-jar.bat`をダブルクリックするとビルドを省略して、そのJARとブラウザ用サーバーだけを起動できます。JARがない場合は何もビルドせず、案内を表示して終了します。

終了するときは、同時に開いた2つの黒いウィンドウを閉じてください。

### 1. ゲームサーバー

PowerShellを開き、次を実行します。

```powershell
cd server
.\mvnw.cmd package
java -jar target\core-defense-server.jar
```

### 2. ブラウザ画面

別のPowerShellを開き、プロジェクトのルートで次を実行します。

```powershell
jwebserver -p 8080
```

ブラウザで <http://localhost:8080/client/> を開きます。クイックマッチ、または合言葉から作成・検索して参加します。ゲスト全員が「準備OK」を選ぶと、ホストが「開始」を押せます。空席はCPUが自動で担当します。複数タブを開けば複数人接続を確認できます。

スマートフォンからゲームを試す場合はPCと同じWi-Fiに接続し、`http://PCのローカルIP:8080/client/`を開きます。PCのファイアウォールでポート8080と8887の許可が必要です。

### Cloudflare Dropへ画面をアップロードする場合

`client`フォルダをアップロードすると、開始画面などの静的ファイルを公開できます。マップはクライアントへ同梱せず、接続時にゲームサーバーから受信します。Cloudflare Dropは静的ファイルだけを公開するため、実際に遊ぶにはJavaゲームサーバーを別途起動し、HTTPSページから接続できるWSSとして公開する必要があります。

## 公開・運用上の注意

このリポジトリは開発中のプロトタイプです。ソースコードをGitHubで公開することはできますが、現在のゲームサーバーはローカル環境または信頼できる家庭内LANでのテストを想定しています。

認証、暗号化されたWebSocket接続、接続元制限、本番向けのアクセス制限はまだありません。ポート8887をインターネットへ直接公開しないでください。一般公開サーバーとして運用する場合は、TLS対応のリバースプロキシ、認証、接続元検証、アクセス頻度制限、監視を追加する必要があります。詳細は[SECURITY.md](SECURITY.md)を参照してください。

GitHub PagesだけではJava製ゲームサーバーは起動しません。ブラウザ部分とは別に、ゲームサーバーを実行できる環境が必要です。

## サーバーコードの構成

- `WasdServer.java`：WebSocket接続、切断、入力受信、定期更新
- `GameSession.java`：ラウンド進行、戦闘、購入、CPUなどのゲームルール
- `MapDefinition.java`：マップのデータ構造とタイル座標変換
- `MapValidator.java`：マップ定義、配置、解放エリアの整合性検証
- `GameMap.java`：マップ読み込み、室内侵入口生成、自由建築可否、衝突判定
- `shared/map.json`：サーバーとブラウザが共通利用するマップ定義
- `GameEntities.java`：プレイヤー、敵、防衛設備の状態
- `SnapshotBuilder.java`：ブラウザへ送る状態データの生成
- `GameConfig.java` / `GameSupport.java`：共通設定値と小さな共通処理

地形、全エリア、端末、作業台、資源、準備延長装置の配置はすべて`shared/map.json`で管理します。Javaサーバーは配置を検証し、室内の敵出現地点を生成して、接続したブラウザへ送信します。クライアント側にはマップ定義を保持しません。変更後はサーバーを再ビルドしてください。

マップ形式はバージョン5です。各エリアは`tiles`に`{"column": 23, "row": 32}`のようなタイル座標（左上が0、0）を列挙します。エリアの`x`、`y`、`width`、`height`は廃止し、凹形状や穴のある形状も定義できます。床タイルのみ指定でき、同じタイルの重複指定（別エリアとの重複を含む）は読み込み時にエラーになります。`world.width`と`world.height`はマップ全体の描画・移動境界として引き続き使用します。

座標は白い床も黒い壁も含むマップ全体を基準にします。`rows[row][column]`が1タイルで、左上が原点、右がX、下がYです。ワールド座標からタイル座標へは`floor(x / tileSize)`、`floor(y / tileSize)`、タイル中心へは`(column + 0.5) * tileSize`、`(row + 0.5) * tileSize`で変換します。現在のタイルサイズは40で、例えば列25・行42の中心は`(1020, 1700)`です。タイル境界上の点は右・下のタイルに属し、物体が壁に接するだけなら衝突せず、はみ出した場合に衝突します。

ターミナルは白い床にも黒い壁にも配置でき、`terminalX`・`terminalY`を表示と操作判定でそのまま使用します。壁への自動移動と`fixedTerminal`は廃止しました。対象エリアの外から近づける位置を指定してください。端末のタイルは通行可能ですが、COREや防衛設備の重ね置きはできません。範囲外の座標、壁上の床専用施設、施設と解放エリアの不一致は読み込み時にエラーになります。

初期ゴールドは全プレイヤー・CPUともに0Gです。再プレイ時も0Gに戻ります。基本装備のPISTOLとBATで攻撃して資金を獲得し、脇部屋を解放して武器を購入します。

武器の性能・保持弾数はサーバーの`GameConfig.java`、販売価格とショップ位置は`shared/map.json`で管理します。弾薬MAXはSHOTGUN 90、SMG 240、RIFLE 96、SNIPER 48、REVOLVER 30、LMG 600、RICOCHET 240、ROCKET 12発。専用ショップではその武器を、AMMOユニットでは所持する全武器を120GでMAXまで補充します。上限を超えず、満タン時は料金を消費しません。PISTOLは弾数無制限です。画面の弾薬上限・レシピ・価格・CORE強化費用・エリア解放費用はサーバーの`rules`通知を使うので、クライアントの数値編集は不要です。

インベントリの装備はマウスやタッチでドラッグ＆ドロップして並べ替えられます。数字キーと持ち替えも同じ順序になり、並び順はブラウザに保存されます。素材は並べ替えの対象外です。

ラウンドクリア報酬は`18 + ラウンド数 × 3`G、攻撃による報酬は従来の2.5倍（敵ごとの総額を整数に四捨五入）です。実際に与えたダメージの割合に応じて支払い、倒した敵からの重複獲得はありません。

## サーバーの自動テスト

サーバーのルール変更後は、次のコマンドで自動テストを実行できます。

```powershell
cd server
.\mvnw.cmd test
```

共通マップ、経路と衝突判定に加え、ラウンド進行、購入、方向射撃と連射、素材採取、クラフト、設置、蘇生、再接続、敵の優先行動、ラウンドイベントを検証します。通常の`package`実行時にも同じテストが実行され、失敗した場合はJARを作成しません。

クライアントからの操作には連番を付け、サーバーの状態通知には処理済み番号を含めています。位置予測は未確認の移動入力を考慮して補正します。通信が切れた場合は30秒間プレイヤー枠を保持し、同じタブからの再接続時に名前、位置、武器などの状態を引き継ぎます。

## 操作

- スマートフォン：画面左側の空き部分を短く長押ししてからドラッグ
- PC：WASDまたは矢印キー
- ダッシュ：PCで移動しながらShiftキーを長押し
- 左クリック／画面右側タッチ：その方向へ射撃（敵を正確にクリックする必要なし）
- 左クリック／タッチ長押し：現在武器の最短射撃間隔で連射
- R（タッチ端末では表示されるRボタン）：近くの仲間、設備、ショップ、解放端末、作業台、COREを操作。ショップでは、その1ユニットが扱う1商品の購入確認を即座に表示
- E：自分のHP、所有武器、弾薬、素材、クラフト済み設置物の一覧を開閉。回復キットを使用でき、素材は1個または全量を地面へドロップ可能
- 開始画面またはEメニューの「遊び方」：目的、操作、防衛の広げ方、画面表示を確認
- マウスホイール：武器と所持している設置物を前後に切り替え
- 数字キー1〜9：一覧の番号に対応する武器・設置物へ直接切り替え
- 右下の武器表示をクリック：武器と設置物を順番に切り替え
- 武器表示下端の細い線：次に攻撃できるまでの回復ゲージ
- 森林／鉱山の素材：近づくだけで自動回収
- WORKBENCHでR：素材から防衛設備をクラフト（完成品は自動選択）
- Eで開く所持品画面：使用する武器や設置するクラフト品を選択
- クラフト品を選択中にR：最後に進んだ方向の正面1タイルへ設置
- COREや設備でR長押し（0.5秒）：画面を開かずに直接持ち上げる。短押しでは従来の操作画面を表示。運搬後は正面の解放済みタイルへRで設置。タッチのRボタンも長押しに対応
- 設置済み設備の近くでR：素材で修理、または所持品へ回収

敵はラウンド1から複数の壁際の入口を使用し、そのラウンド中は同じ出現地点に固定されます。入口の壁には茶色の目印があり、出現中は赤色になります。ラウンド8から解放済みの室内入口が加わり、ラウンド10から一部の武器個室、ラウンド12からREVOLVERを含む全武器個室が候補になります。出現は選ばれた入口を順番に巡回します。WOOD、ORE、TIME CONTROLの個室は出現対象に含みません。COREを奥へ移すほど防衛線も段階的に移動します。敵ごとに進行方向を少しずらし、完全な一列には並ばないようにしています。

資源の出現場所で拾える量は銅2個、鉄3個、銀1個です。鉱山には鉄の出現場所を1か所追加しています。銀タレットには銀8個が必要です。ラウンドクリア時はダウンした全員がHP45で自動復帰します。ゲーム中は左上の「退出」から確認後にホームへ戻れます。照準カーソルは設定で点・×・＋を選べ、色と大きさも保存されます。

マップ調整時はURLへ`?debug=1`を付けると、全出現地点、進軍経路、現在使用中の地点をマップ上で確認できます。デバッグモードのホストがゲームを開始すると、ホストは100000Gと全武器（弾薬満タン）を所持した状態になります。再プレイ時も同じ状態で開始します。

侵入口ごとにRUNNERが多い、BRUTEが多い、プレイヤーを追いやすい、防衛設備を壊しやすいといった違いがあります。停電時は自分の周囲だけが見え、ラウンド20以降はブレーカーが1台または2台落ちます（3台は発生しません）。すべて復旧すると照明が戻り、扉故障時は橙色の故障入口から敵が集中し、BOSSはCORE付近で範囲パルスを使用します。

50ラウンドに合わせて、R10から高耐久のARMORED、R18から高速でプレイヤーを狙うHUNTER、R26から設備を優先して壊すSIEGE、R34から耐久・速度・攻撃力を兼ね備えるCHAMPIONが出現します。4ラウンドごとのボスはR24からWARLORD、R40からTITANへ強化され、CORE付近の範囲パルスも6秒間隔から5秒、4秒へ速くなります。種類は色・大きさ・名前で区別でき、新ボスにもHPを表示します。

R40以降は通常敵の数を従来の2倍から毎ラウンド0.2倍ずつ増やし、端数を切り上げます（R40:252体、R43:351体、R50:624体）。ボス回のボス数も2倍です。通常敵・ボスともに1回の出現をR40〜42は2体、R43〜45は3体、R46〜48は4体、R49〜50は5体に増やし、複数の侵入口へ続けて出現させます。

購入、回復、採取、クラフト、建設、修理、CORE強化は準備時間中と戦闘中の両方で行えます。戦闘中も敵の攻撃は止まらないため、周囲の安全を確認して利用してください。

ゲーム中のUIは白・黒・灰色を基本に、状態を伝えるライトブルーとレッドをアクセントにしています。上部中央に`ROUND 3`形式のラウンドと敵数／次ラウンド時刻、左下に自分の体力を示すハートとゴールド、右上に仲間HPバーとゴールド、右下に武器と攻撃クールダウンを表示します。自分のプレイヤータイルは青です。プレイヤーのダウンは赤いログ、攻撃で得たゴールドは敵付近のライトブルー表示で確認できます。ボスにはHPバーと現在値／最大値を表示し、通常敵は命中時だけ赤く光ります。COREはタイル内のライトブルーの割合、仲間は右上のバーで残りHPを確認できます。

## 現段階の範囲

ルーム作成・一覧参加に対応したゲームループと防衛システムの検証版です。公開ルームの検索条件、アカウント、永続アンロック、完成版アートはまだ含みません。

効果音の入口は`client/sound.js`です。武器ごとの発射音、回復、設置、採取の音をサーバーのイベントに応じて再生します。`client/sounds/`の空MP3を同名の実素材で置き換えてください。空ファイルの再生失敗は静かに処理します。

## 所持品UIの回帰確認

ルーム周辺の回帰テストはプロジェクト直下で`node client/tests/rooms.cjs`を実行します。名前入力によるボタン切替、作成失敗後の再試行、参加・退出・再接続を確認します。サーバーをビルドした後、Node.js 22以上で`node client/tests/rooms-server.cjs`を実行すると、ローカルの一時サーバーで作成・一覧・2人参加・準備・開始を確認します。Windowsでは`JAVA_HOME`をJDKのフォルダーに設定してください。

武器の所持品表示・弾数・補充メニューは`node client/tests/weapons.cjs`、設置とショップ表記は`node client/tests/placement.cjs`で確認できます。

通常のブラウザ用サーバーを起動し、/client/tests/inventory.html を開くと、実際の所持品コードで通信更新を挟むドロップ操作・最新数量・キーボードフォーカス等の9項目を確認できます。PASS 9 checks が成功です。

スナイパーは単発280・射程2400で敵を貫通。レボルバーは単発320でスナイパーより高火力です。ロケランは奥のSECURITY HALLから解放するROCKET ROOMで1400Gで購入でき、射程1200・発射間隔1.8秒。狙った地点、最初に接触する敵、手前の壁で爆発し、半径200内の敵に中心800〜外周400のダメージとノックバックを与えます。爆風は壁で遮られ、味方・コア・設備にはダメージを与えません。バリケードはHP1200で、描画と体力バーを1ブロック内に収めています。コアにはシールドの現在値／最大値を表示します。

RICOCHETはDUAL PISTOLに代わる反射銃です。1射で1発消費し、壁で最大3回反射、総射程1000・威力72・発射間隔0.3秒です。敵に当たると停止します。射撃は照準方向への直線で、敵への自動照準はありません。武器ショップまたはAMMOで補充に成功すると操作画面と所持品画面が閉じます。

QUARRYは持ち運べる素材製造装置です。販売所はマップ奥のFOREST LAB（木材4,000G）、MINE LAB（鉄5,000G）、SECURITY HALL（銅7,000G）、COMMAND ROOM（銀10,000G）に分散しています。同じ種類も複数購入でき、所持品に個数をまとめて表示します。選択してRで1台ずつ設置し、残りがあれば続けて設置できます。設置した装置はRのPICK UPまたはR長押しで回収できます。各装置は独立して木材・鉄を5秒、銅を8秒、銀を12秒ごとに1個製造し、装置を中心とした9×9タイル内のランダムな空き床へ素材をドロップします。壁・未開放エリア・設備・キャラクター・既存の素材がある場所には落としません。空き床がない周期は製造を見送り、装置内に在庫や未出力分は保持しません。落ちた素材は近づいたプレイヤーが回収します。運搬中とゲーム終了後は製造せず、回収・再設置で製造進捗をリセットします。ゲーム再開始時に購入した装置とドロップ素材をリセットします。
